# Верификация таджикской локализации (R7 / SP3-03)

Согласно правилу **R7**, машинные черновики переводов **запрещено** помечать как `verified` и загружать в релизную базу `tech_english.db` без проверки носителем языка / владельцем проекта.

## Файлы для ревью владельцем
1. `docs/tg_review/ui_strings_tg_draft.json` — черновики строк пользовательского интерфейса (`status = "pending_review"`). После проверки и одобрения перенесите одобренные строки в `app/src/main/res/values-tg/strings.xml` и соберите релиз с флагом `TAJIK_UI_LOCALIZATION_ENABLED=true`.
2. `docs/tg_review/terms_tg_draft.csv` — черновики переводов приоритетных IT-терминов (`status = pending_review`).

## Текущее фактическое состояние релизной БД (`tech_english.db`)
- Всего верифицированных академических терминов: **20 658**
- Человечески верифицированных `translation_tg` в релизной БД: **19**
- Остаток до целевого ориентира `≥ 2 000` верифицированных терминов: **1 981** (требуется ручная верификация носителем языка)

## Импорт одобренных записей
После того как переводчик проверит строки в `terms_tg_draft.csv` и сменит колонку `status` с `pending_review` на `verified`, запустите:

```bash
python3 scripts/import_verified_tg.py --input docs/tg_review/terms_tg_draft.csv --dry-run
```

Скрипт строго пропускает любые строки со статусом, отличным от `verified`.
